## Resumen

El objetivo de este documento es presentar, mediante ejemplos, los conceptos básicos de **Spring MVC**, un marco de trabajo web en Java basado en el **modelo MVC (Modelo – Vista – Controlador)**.

Spring MVC forma parte del ecosistema del **Spring Framework** y ofrece un marco estructurado para el desarrollo de aplicaciones web en Java robustas y fáciles de mantener.

El curso también aborda **Thymeleaf**, un motor de vistas moderno y potente que está muy bien integrado en Spring MVC.

## Público objetivo

Este curso está dirigido a lectores con un **buen dominio del lenguaje de programación Java**.

**No se requieren conocimientos de programación web**, ya que los conceptos se introducen paso a paso.

## Alcance del documento

Aunque este documento es bastante detallado, no pretende ser exhaustivo.  
Spring es un marco de trabajo extenso, compuesto por numerosos componentes y extensiones.

El documento está diseñado para poder leerse **sin computadora**, lo que explica la presencia de numerosas **capturas de pantalla**.
